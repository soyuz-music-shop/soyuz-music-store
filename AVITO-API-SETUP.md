# Цены Avito в каталоге Союз Мьюзик

Синхронизация запускается вместе с Ozon каждый час и по кнопке «Обновить сейчас» в закрытой панели управления.

1. Ozon обновляет карточки, остатки, описания, фото и свою цену.
2. Avito API возвращает активные объявления продавца.
3. Если товар сопоставлен однозначно, его цена заменяется ценой Avito.
4. Если совпадения нет, оно неоднозначно, цена пустая или Avito временно недоступен, остаётся цена Ozon.

## Где менять ключи

Откройте `soyuz-office-9911.html`, подключите GitHub token и заполните блок «Цены из каталога Avito».

Админка создаёт или заменяет два GitHub Actions Secret:

- `AVITO_CLIENT_ID`
- `AVITO_CLIENT_SECRET`

Значения шифруются открытым ключом GitHub прямо в браузере. GitHub Secrets нельзя прочитать обратно — их можно только заменить.

Для этой операции fine-grained GitHub token должен иметь доступ к репозиторию `soyuz-music-store` и разрешения:

- Contents: Read and write
- Actions: Read and write

## Как сопоставляются товары

Сначала проверяется явный идентификатор Avito в поле `avitoId` или характеристике `Avito ID`. Затем используется точное нормализованное название «артист + название». Совпадение без уточнений в скобках применяется только тогда, когда оно единственное и в каталоге Ozon, и в каталоге Avito.

Это специально не использует нечёткий поиск: похожие издания, разные цвета пластинок и переиздания не должны получать чужую цену.
