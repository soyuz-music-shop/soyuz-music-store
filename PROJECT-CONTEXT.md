# Союз Мьюзик — контекст проекта

## Что это

Статический интернет-магазин Союз Мьюзик на GitHub Pages. Сайт работает без платного хостинга, подстраивается под светлую и тёмную тему устройства, содержит каталог, фильтры, поиск, избранное, корзину и подробные карточки товаров.

Публичный адрес: `https://varvara9911.github.io/soyuz-music-store/`

Репозиторий: `varvara9911/soyuz-music-store`, ветка `main`.

Текущая версия интерфейса: `28`. На главной и в личном кабинете уменьшены избыточные вертикальные пустоты на компьютерах и телефонах: компактнее стали первый экран, иллюстрация с винилом, отступы категорий, «О нас», каталога и подвала; карточки товаров и их изображения не изменялись. Личный кабинет вынесен на отдельную страницу `account.html`; кнопка пользователя в шапке ведёт туда, а после авторизации на странице остаются только данные пользователя, лист ожидания и управление аккаунтом. Кнопка «Очистить фильтры» расположена только внутри боковой панели фильтров, рядом с категориями, артистами, наличием и ценой. Кнопка «Поиск» прижата к правому краю поисковой строки на компьютере и телефоне. В мобильной версии поиск расположен отдельной строкой шапки и не перекрывает каталог. Поиск из шапки сбрасывает скрытые фильтры и выполняется по всему каталогу. Кнопка «Показать ещё» скрыта при пустой выдаче. При входе категория сбрасывается на «Все». Регистрация сохраняет имя и контактную почту; в шапке отображается имя, а окно авторизации автоматически закрывается после успешного входа или регистрации. Отсутствующие товары можно добавить в защищённый лист ожидания Supabase. Лист ожидания с текущими статусами доступен в личном кабинете по нажатию на имя пользователя. В панели пользователя заметно расположены кнопки «На главную» и «Выйти»; переход на главную также доступен из окна уведомлений. О поступлении сообщает колокольчик рядом с именем, а подключаемая почтовая доставка поддерживает Mail.ru SMTP и Resend. В личном кабинете пользователь может удалить свой аккаунт и связанные с ним данные листа ожидания. Тема выбирается компактным переключателем с одновременно видимыми солнцем и луной; выбор сохраняется на устройстве, а до первого выбора используется системная тема. В светлой теме кнопка «Сообщить о поступлении» серая и визуально отличается от золотой кнопки покупки. После подписки она становится зелёной, получает галочку и текст «В листе ожидания». В иконке вкладки браузера используется фирменный логотип Союз Мьюзик. Навигация «О нас» ведёт к отдельному адаптивному блоку о команде и учитывает высоту закреплённой шапки. В заголовке «О нас» слово «Мы» начинается с новой строки, а перед названием используется короткий дефис.

## Основные файлы

- `index.html`, `styles.css`, `app.js` — магазин.
- `products.json` — основной каталог товаров.
- `soyuz-office-9911.html`, `admin.css`, `admin.js` — закрытая от навигации панель управления.
- `admin-overrides.json` — ручные изменения, добавленные и скрытые товары.
- `auth.js`, `auth-config.js` — регистрация и вход по телефону через Supabase Auth.
- `supabase-waitlist.sql` — таблица и политики защищённого листа ожидания.
- `WAITLIST-EMAIL-SETUP.md` — секреты почтовой доставки уведомлений.
- `scripts/import_ozon_excel.py` — импорт Excel-шаблонов Ozon.
- `scripts/sync_ozon.py` — почасовое обновление дат публикации и остатков через Ozon Seller API.
- `.github/workflows/import-excel.yml` — автоматический импорт загруженных Excel-файлов.
- `.github/workflows/sync-ozon.yml` — почасовая синхронизация Ozon.

## Каталог

Каждая запись в `products.json` содержит:

```json
{
  "id": "артикул Ozon",
  "category": "vinyl | cd | tape | book | movie",
  "artist": "артист или автор",
  "title": "название и параметры в скобках",
  "price": 0,
  "oldPrice": 0,
  "available": false,
  "stock": 0,
  "year": 0,
  "format": "носитель",
  "detail": "краткая деталь",
  "publishedAt": "YYYY-MM-DD",
  "badge": "Новинка или пустая строка",
  "image": "URL главного фото",
  "image2": "URL второго фото",
  "images": [],
  "description": "описание и треклист",
  "specs": {},
  "genre": "",
  "publisher": "",
  "source": "music | book | manual"
}
```

На карточке артист и основное название показываются крупно. Текст с первой открывающей скобки выводится отдельной более мелкой строкой. Изображения товара показываются целиком через `object-fit: contain`.

## Админка

Панель открывается только по отдельному адресу `/soyuz-office-9911.html`; ссылки на неё в публичном магазине нет. Она позволяет:

- искать и фильтровать товары;
- менять все основные поля карточки;
- добавлять товар вручную;
- скрывать и восстанавливать товар;
- сбрасывать ручные изменения к данным Ozon;
- загружать один или несколько `.xlsx` шаблонов Ozon.

Для записи в репозиторий используется fine-grained GitHub token с разрешением `Contents: Read and write` только для этого репозитория. Токен не сохраняется в коде, `localStorage` или `sessionStorage`, а живёт только в памяти открытой вкладки.

Ручные изменения хранятся отдельно в `admin-overrides.json`, поэтому автоматическая синхронизация `products.json` их не перезаписывает.

## Импорт Excel Ozon

Поддерживаются шаблоны:

- «Кино, музыка, видеоигры, софт»;
- «Печатная книга».

Импорт выполняет обновление по артикулу: новые товары добавляются, существующие обновляются, отсутствующие в файле товары не удаляются. Остаток и дата публикации существующей позиции сохраняются до следующего ответа Ozon API.

Админка загружает Excel во временную папку `imports/` отдельным Git-коммитом. Workflow разбирает файл, обновляет `products.json`, удаляет временный Excel и публикует результат.

## Автоматическое обновление Ozon

Workflow запускается каждый час. Он получает из Ozon новые позиции, названия, характеристики, описания, фотографии, цены, даты публикации и остатки. Он использует GitHub Actions secrets:

Описание отдельно запрашивается для каждой новой или изменённой карточки. Поле `_ozonUpdatedAt` хранит техническую дату последнего обновления Ozon и позволяет не делать тысячи лишних запросов каждый час.

- `OZON_CLIENT_ID`
- `OZON_API_KEY`

Ключи нельзя добавлять в исходный код или передавать в публичный архив.

## Регистрация пользователей

Интерфейс регистрации и входа добавлен на главную страницу. Логин — номер телефона, пароль пользователь придумывает сам, есть галочка «Запомнить меня».

Авторизация подключена к бесплатному проекту Supabase `soyuz-music-shop`. Обязательное подтверждение email отключено, поэтому пользователь видит только номер телефона и придуманный пароль. Публичные значения хранятся в `auth-config.js`:

```js
window.SOYUZ_AUTH_CONFIG = {
  url: "https://sprvfwqqqktrcmalzbcq.supabase.co",
  anonKey: "sb_publishable_..."
};
```

`anonKey` является публичным клиентским ключом. `service_role` и другие секретные ключи в сайт добавлять нельзя.

Удаление аккаунта выполняется защищённой функцией `delete_own_account()`: удалить можно только текущего авторизованного пользователя. Записи его листа ожидания удаляются каскадно.

## Уведомления о поступлении

При появлении ожидаемого товара в наличии пользователь видит уведомление под колокольчиком рядом с именем. Прочитанное состояние хранится в поле `waitlist.read_at` и защищено RLS.

Почтовая отправка подготовлена для двух способов:

- обычный ящик Mail.ru через SMTP и отдельный пароль приложения;
- Resend с подтверждённым адресом на собственном домене.

Все имена секретов и порядок подключения перечислены в `WAITLIST-EMAIL-SETUP.md`. Почтовые пароли и API-ключи не должны попадать в Git.

## Важные правила проекта

- Не обрезать изображения товара в превью.
- Носители обозначать как `LP`, `CD`, `MC` и не дублировать одинаковые метки.
- Новинки определять по дате публикации карточки Ozon.
- Треклист в описании всегда выводить в столбик.
- Артистов объединять без учёта регистра.
- Список артистов прокручивается и поддерживает поиск по кириллице и латинице.
- Фильтр каталога закреплён при прокрутке на компьютере.
- При открытии сайт должен начинаться сверху, а не переходить сразу к каталогу.
- Светлая и тёмная тема выбираются через `prefers-color-scheme`.
- Секреты Ozon, GitHub и Supabase `service_role` не коммитить.

## Локальная проверка

Из корня проекта:

```powershell
python -m http.server 4173
```

Открыть:

- `http://127.0.0.1:4173/`
- `http://127.0.0.1:4173/soyuz-office-9911.html`

Перед публикацией проверить JavaScript и импорт:

```powershell
node --check app.js
node --check auth.js
node --check admin.js
python -m py_compile scripts/import_ozon_excel.py
git diff --check
```
