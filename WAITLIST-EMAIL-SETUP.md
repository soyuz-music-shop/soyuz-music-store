# Письма и уведомления о поступлении

Лист ожидания хранится в Supabase. Почасовая синхронизация Ozon определяет переход товара из состояния «нет в наличии» в состояние «в продаже». После этого пользователь получает уведомление под колокольчиком в личном кабинете и письмо, если подключён один из почтовых вариантов ниже.

Страница GitHub Actions Secrets:

https://github.com/varvara9911/soyuz-music-store/settings/secrets/actions

Обязательный секрет базы:

- `SUPABASE_SERVICE_ROLE_KEY` — секретный service role key проекта Supabase.

## Вариант 1: обычная почта Mail.ru через SMTP

Подходит для запуска до появления собственного домена. Сначала владелец создаёт почтовый ящик и отдельный пароль приложения в настройках безопасности Mail.ru. Основной пароль от ящика использовать и передавать не нужно.

Ящик `soyuz_music_shop@mail.ru`, SMTP-сервер, порт и имя отправителя уже внесены в workflow. Добавить нужно только один почтовый секрет:

- `MAIL_SMTP_PASSWORD` — отдельный пароль приложения Mail.ru.

В настройках безопасности Mail.ru также должен быть разрешён доступ по IMAP, POP и SMTP.

## Вариант 2: собственный домен через Resend

Предпочтительный вариант после появления домена. Добавить секреты:

- `RESEND_API_KEY` — API-ключ Resend;
- `WAITLIST_FROM_EMAIL` — подтверждённый отправитель, например `Союз Мьюзик <notifications@soyuz-music.ru>`.

Если настроены оба варианта, синхронизация использует Resend. Для переключения на Mail.ru достаточно удалить или очистить секреты Resend.

Секретные значения нельзя записывать в репозиторий, архив проекта или клиентский JavaScript. Пока почтовые секреты не добавлены, лист ожидания и уведомления под колокольчиком работают, но письма не отправляются.
