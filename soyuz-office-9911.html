1

Доступ для ручного редактирования

Автоматическое обновление каталога уже подключено. Личный токен нужен для публикации ручных правок, запуска синхронизации и безопасной замены API-ключей. Он хранится только в этой вкладке браузера и исчезает после её закрытия.

Нужен fine-grained token с доступами Contents и Actions: Read and write к этому репозиторию.

2

Цены из каталога Avito

Введите Client ID и Client Secret из кабинета Avito. Значения шифруются в браузере и сохраняются прямо в GitHub Secrets — сама админка их не показывает и не хранит.

Подключите GitHub в первом блоке, затем сохраните оба ключа.

3

Обновление каталога из Ozon и Avito

Ozon обновляет позиции, остатки, описания, характеристики и фотографии. Цена берётся из Avito, если позиция там найдена однозначно; иначе остаётся цена Ozon.

Автоматическая проверка выполняется каждый час. Для немедленного запуска откроется GitHub Actions.
