Каталог без сложных таблиц

Редактируйте карточки вручную, загружайте Excel Ozon и обновляйте цены из XML Avito.

Автоматизация GitHub подключена

1

Первичное подключение админки

Этот технический шаг нужен только один раз. После успешного подключения доступ сохранится в этом браузере, а блок исчезнет.

Подключите админку один раз — повторно вводить токен не придётся.

2

Цены из каталога Avito

Введите Client ID и Client Secret из кабинета Avito. Значения шифруются в браузере и сохраняются прямо в GitHub Secrets — сама админка их не показывает и не хранит.

Подключите GitHub в первом блоке, затем сохраните оба ключа.

3

Цены из XML Avito

Загрузите выгрузку Avito в формате .xml или .xml.gz. Цены сопоставятся по артикулу или штрихкоду, а для позиций без совпадения сохранится цена Ozon.

Перетащите .xml или .xml.gz сюда или нажмите, чтобы выбрать файл
Файл не выбран

Файл обрабатывается в браузере: исходный XML никуда не публикуется, в GitHub сохраняется только компактный список цен.

4

Обновление каталога из Ozon и Avito

Ozon обновляет позиции, остатки, описания, характеристики и фотографии. Для цены сначала используется последняя загруженная XML-выгрузка Avito, затем API Avito; если совпадения нет, остаётся цена Ozon.

Автоматическая проверка выполняется каждый час. Для немедленного запуска откроется GitHub Actions.

Подойдут ваши шаблоны «Кино, музыка, видеоигры, софт» и «Печатная книга». Можно выбрать оба файла сразу.

Перетащите .xlsx сюда или нажмите, чтобы выбрать файлы

6

Текст «О нас»

Здесь можно изменить заголовок и весь текст блока. Пустая строка в большом поле начинает новый абзац.

Высота раздела подстраивается под содержимое. На небольших экранах шрифты уменьшаются автоматически.

Для публикации подключите GitHub в первом блоке.

Оформление

Шапка «Новинки» — карусель

Выбирайте товары только для перехода в карточку. Для каждого релиза самостоятельно загрузите PNG. Изображение помещается целиком на любом экране, а облегчённая копия ускоряет загрузку. Цен в карусели нет. В каждой позиции можно отдельно изменить артиста, полное название со скобками и текст, не меняя сам товар.
